# Book Sales and Publishing Analysis

This project is created using Tableau Public. It analyzes book sales, ratings, prices, publishers, authors, and customer checkouts.

## Dashboards

### Book Pricing and Ratings
- Average book price by genre and format
- Distribution of book ratings
- Ratings and award alignment by genre
- Average discount by genre and format

### Seasonal Trends
- Monthly checkout trends by genre
- Sales trends by month
- Longest time between book editions
- Correlation between ratings, print run size, sales, and checkouts

### Book Popularity and Publishers
- Most and least popular books
- Author details
- Publisher specialization by genre
- Writing time versus book success

## Tools Used
- Tableau Public
- Book sales dataset

## Purpose
The purpose of this project is to understand book performance and identify patterns in sales, ratings, prices, genres, and publisher activity.
