# MTCars Data Analysis using Python

## Project Overview
This project analyzes the **MTCars** dataset using Python. The dataset contains information about 32 cars and 11 vehicle features, including fuel efficiency, engine size, horsepower, weight, transmission type, and number of gears.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Pydataset

## Dataset Columns
- `mpg` - Miles per gallon
- `cyl` - Number of cylinders
- `disp` - Engine displacement
- `hp` - Horsepower
- `drat` - Rear axle ratio
- `wt` - Vehicle weight
- `qsec` - Quarter-mile time
- `vs` - Engine shape
- `am` - Transmission type
- `gear` - Number of forward gears
- `carb` - Number of carburetors

## Tasks Performed
- Loaded the MTCars dataset using `pydataset`
- Checked dataset structure, columns, data types, and summary statistics
- Checked for missing values
- Calculated mean MPG, maximum horsepower, and minimum/maximum vehicle weight
- Counted cars by number of cylinders
- Compared average MPG by cylinders, transmission type, and number of gears
- Created a pivot table to compare MPG by cylinders and transmission
- Created an `efficiency` column to classify cars as high or low efficiency
- Converted coded values into readable labels:
  - Automatic and Manual transmission
  - V-shaped and Straight engine
- Created visualizations including bar charts, scatter plots, histograms, and box plots

## Key Learning
This project helped me practice data analysis with pandas. I learned how to inspect data, check missing values, group data, create new columns, use pivot tables, and visualize relationships between vehicle features.

## Conclusion
The analysis showed how vehicle characteristics such as cylinders, weight, horsepower, and transmission can be compared with fuel efficiency. This assignment improved my Python, pandas, and data visualization skills.
