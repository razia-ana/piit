# Sales Data Analysis using Google Sheets

## Project Overview
This project analyzes sales data using Google Sheets formulas, filters, sorting, conditional formatting, and lookup functions.

## Skills Used
- Google Sheets
- Data cleaning and sorting
- Basic data analysis
- Spreadsheet formulas
- Conditional formatting

## Tasks Performed
- Froze the top row for easier navigation
- Applied filters and sorted revenue in descending order
- Calculated total revenue using `SUM`
- Calculated average revenue using `AVERAGE`
- Counted records using `COUNTA` and `COUNT`
- Used `COUNTIF` to count orders from the North region
- Used `SUMIF` to calculate total revenue for the Electronics category
- Used `AVERAGEIF` to calculate the average units sold by Asha
- Highlighted high-revenue values using conditional formatting
- Identified duplicate Order IDs using conditional formatting
- Used `VLOOKUP` and `XLOOKUP` to retrieve category information
- Used `QUERY` to summarize revenue by region
- Used `SORT` to display data by units sold
- Found the highest and lowest revenue using `MAX` and `MIN`
- Calculated each row’s percentage contribution to total revenue
- Used an `IF` formula to label revenue as High or Low
- Protected formula cells

## Key Results
- Total revenue: 23,240
- Average revenue: 930
- Total revenue for Electronics: 16,120
- Average units sold by Asha: 8

This assignment improved my Google Sheets and spreadsheet analysis skills. I learned how to use formulas, filters, conditional formatting, lookups, and summary functions to answer business questions from sales data.
